# WinBox Agent Skills

本目录是 WinBox 的**质量护栏**：贡献者不需要先成为 C# 大佬，但必须按流程做事。流程负责捍卫**维护、测试、交付、分发**的质量；贡献者贡献**热忱与创意**；AI 通过这些 skills 提供**零成本启动**与持续护航。

| Skill | 何时用 |
|-------|--------|
| [winbox-onboarding](winbox-onboarding/SKILL.md) | 第一次进仓、环境不通、不知道从哪开始 |
| [winbox-change-loop](winbox-change-loop/SKILL.md) | **任何代码/协议改动**（默认必走） |
| [winbox-architecture](winbox-architecture/SKILL.md) | 放文件、加项目、改引用、扩插件边界 |
| [winbox-ui](winbox-ui/SKILL.md) | 唤起层 / 托盘 / 设置 / 结果行 / 滚动与主题 |
| [winbox-testing](winbox-testing/SKILL.md) | 写测试、补测试、解读测试失败、对齐 CI |
| [winbox-ship](winbox-ship/SKILL.md) | PR 准备、评审、发版与分发 |

人类可读的入门仍以仓库根目录 [CONTRIBUTING.md](../../CONTRIBUTING.md) 为准；skills 是给 Agent 执行的操作手册。
